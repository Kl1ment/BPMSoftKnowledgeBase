В справочнике "Права доступа на операции" (SysAdminOperation) создаем новую операцию

Далее в коде можно получить право доступа пользователя

```JS
RightUtilities.checkCanExecuteOperation({ 
	operation: "CanChangeManager" 
}, function (isCanSendToPurchareGroup) {
	this.set("ChangeManagerButtonsVisibleByRole", isCanSendToPurchareGroup);
}, this);
```
